# 구현 인계 (새 세션용)

새 세션은 **이 파일과 `docs/DESIGN.md`만 읽고** 시작한다.

## 현재 상태
- 1단계(기능 제거 + 개인 정보 정리)는 이전 세션에서 진행했다. `git log --oneline`으로 1단계 커밋이 있는지 먼저 확인한다. 커밋이 없으면 1단계부터 다시 한다.
- 다음은 `DESIGN.md` §8의 **2단계(Codex CLI 연결)** 부터다. 2 → 3 → 4 → 5 → 6 → 7 순서로 진행한다.

## 진행 규칙
1. 단계마다 TDD로 진행하고, `uv run pytest -q`가 전부 통과하면 커밋한다. 커밋 메시지 끝에는 `Co-Authored-By` 줄을 넣는다.
2. 단계를 끝낼 때마다 `uv run python tools/privacy_check.py`를 돌려 0건인지 확인한다.
3. **GitHub 저장소는 공개다.** 원격 추가와 push는 7단계가 모두 끝나고, 개인 정보 검사 + 사람이 직접 점검한 뒤 **사용자 확인을 받고** 한다. 이미지·스크린샷은 올리지 않는다(아이콘 제외).
4. 원본 앱 폴더는 읽기만 하고 고치지 않는다(위치는 감독자에게 묻는다).
5. 비밀번호·토큰은 스크립트에 넣지 않는다. Tailscale 로그인과 Codex(ChatGPT) 로그인은 사용자가 브라우저에서 직접 한다.
6. 사용자(동생)는 왕초보다. 화면 문구와 안내서는 쉬운 한국어로, 설치는 더블클릭 한 번으로 끝나게 만든다.

```
git log 로 1단계 완료를 확인한 다음 §8의 2단계부터 순서대로 구현해줘. 단계마다 테스트와 privacy_check 통과 후 커밋하고, push 는 하지 마.
```
