홈 화면에 추가하고 알림 받기

아이폰에서는 이 앱을 홈 화면에 추가해야 알림을 받을 수 있어요. 아래 순서대로 해 주세요.

  1. Safari로 이 주소를 열었는지 확인해요. (다른 앱 안의 브라우저에서는 안 돼요.)
  2. 화면 아래 가운데의 공유 버튼(네모에서 화살표가 위로 나가는 모양)을 눌러요.
  3. 목록을 밀어 올려 홈 화면에 추가를 누르고, 오른쪽 위의 추가를 눌러요.
  4. 홈 화면에 생긴 가족 비서 아이콘으로 앱을 다시 열어요.
  5. 이 화면에서 아래 알림 켜기를 누르고, 알림을 허용해 주세요.
